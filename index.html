О ТИПАХ АККАУНТОВ

          

            
ОФЛАЙН
Локальный профиль с UUID. Не требует входа, подходит для одиночной игры и пользовательских серверов.

            
ELY.BY
Полноценная авторизация через Ely.by. Лаунчер получает токен и подключает authlib-injector для входа на серверы с онлайн-режимом Ely.

          

          
Для официальных серверов Mojang/Microsoft требуется лицензионная учётная запись. Проект не содержит обходов авторизации.
